# CS 2420 diagram images

Public copies of the diagrams referenced from the CS 2420 Canvas pages. The CT repos are
private, so Canvas cannot hotlink their `images/` folders; this repo is what the `<img>`
tags point at.

Each folder matches a Code-Together. `svg/` holds the editable source, the `.png` beside
it is what Canvas actually loads (rendered at 2x by `scripts/svg_to_png.py` in the course
repo).

**Editing:** change the SVG in the CT repo first, re-render, then copy both files here.
Renaming a file breaks every Canvas page that links it.
